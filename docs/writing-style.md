# How we write here

- Use plain Indian English. Keep it direct and relaxed.
- Start with the thing we learnt, then say how we learnt it.
- Prefer a concrete example over a big abstract claim.
- Keep the original author's wording when editing an existing narrative (this helps preserve pieces of an idea you might have missed).
- Say the sample size and the limit of the result.
- Keep failures and reversals. They are useful memory.
- Avoid product language, dramatic headings and polished consultancy prose.
- Avoid filler such as “in today's rapidly changing landscape”.
- Use technical words when they save time, but explain uncommon ones once.
- Link measured claims to evidence checked into this repository.
- If the evidence is partial or private, say that in one clean sentence.

The aim is not to sound formal but to make the thoughts behind the experiments
easy to check and hard to misunderstand.
